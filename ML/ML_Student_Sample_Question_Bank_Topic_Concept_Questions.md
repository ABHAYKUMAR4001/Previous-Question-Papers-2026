## Instance-Based Learning
### Concept: Basic k-NN classification
- Compute Euclidean distances to a query point, select k nearest neighbours and classify by majority vote.

### Concept: Distance-weighted nearest neighbour / KDE
- Use distance/kernel-density weighting to classify a query point.

### Concept: Locally Weighted Regression
- Use a Gaussian kernel to weight nearby observations and fit a local regression for a query point.
